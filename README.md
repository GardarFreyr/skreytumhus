# Skreytum Hús – ný forsíða (hönnunartillaga)

Kyrrstæð kynningarútgáfa af endurhannaðri forsíðu fyrir [skreytumhus.is](https://www.skreytumhus.is/).
Þetta er hönnunartillaga og hún snertir ekki lifandi vefinn.

- Efni, færslur, myndir og þættir eru sóttir af skreytumhus.is (staðan 20. nóvember 2026). Allir hlekkir vísa á upprunalegar færslur og safnið.
- `index.html`: forsíðan, `css/style.css`: útlit, `js/app.js`: síur, val á sjónvarpsþætti og valmynd í síma.
- Engin smíðaskref. Opnaðu `index.html` eða keyrðu `python3 -m http.server` í möppunni.

Instagram- og Facebook-slóðirnar (`skreytumhus`) eru ágiskun og þarf að staðfesta.
